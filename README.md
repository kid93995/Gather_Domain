# Gather_Domain
Extract subdomains from a JSON file.



A lightweight and efficient utility tool designed to parse JSON files and extract subdomains effortlessly. 

## 🚀 About The Tool
Whether you downloaded a JSON file from a reconnaissance scan, a bug bounty platform, or any other source, this tool automatically parses the file, filters out all unrelated metadata and extra information, and isolates only the target subdomains for you.

## ⚙️ How to Use
1. Run the script/tool in your terminal:
2. Specify the location of your JSON file.
